from scapy.layers.inet import IP, TCP, ICMP
import socket
import requests

def identificar_os(ttl):
    if ttl <= 64:
        return "Linux/Android/Mac"
    elif ttl <= 128:
        return "Windows"
    else:
        return "Desconhecido"

# --- NOVIDADE: PEGAR DADOS DA PRÓPRIA MÁQUINA ---
def pegar_meu_mac_ip():
    try:
        # Pega a interface padrão que o Scapy está usando
        mac = scapy.get_if_hwaddr(scapy.conf.iface)

        # Pega o IP local (truque do socket UDP)
        s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        s.connect(('8.8.8.8', 1))
        ip = s.getsockname()[0]
        s.close()

        return {'ip': ip, 'mac': mac, 'vendor': 'ESTE DISPOSITIVO (HOST)'}
    except:
        return None

def analisar_host(ip, mac, vendor_pre_definido=None):
    print(f"\n[+] Analisando: {ip} ({mac})")

    # Se já passamos o fabricante (caso seja o próprio PC), usa ele
    if vendor_pre_definido:
        vendor = vendor_pre_definido
        os_guess = "Windows/Linux (Host Local)"
    else:
        vendor = get_mac_vendor(mac)
        # Tenta Ping para descobrir OS
        os_guess = "Não respondeu Ping"
        try:
            resp = scapy.sr1(IP(dst=ip) / ICMP(), timeout=1, verbose=0)
            if resp:
                os_guess = f"{identificar_os(resp.ttl)} (TTL={resp.ttl})"
        except:
            pass

    print(f"    ► Fabricante: {vendor}")
    print(f"    ► Sistema: {os_guess}")
    print("-" * 50)

def escanear_rede_ultimate(ip_range):
    print(f"\n🚀 SCAPY SCANNER - Iniciando em {ip_range}")
    print("=" * 60)

    # 1. ARP Discovery (Vê os Vizinhos)
    arp = scapy.ARP(pdst=ip_range)
    ether = scapy.Ether(dst="ff:ff:ff:ff:ff:ff")
    pacote = ether / arp
    resultado = scapy.srp(pacote, timeout=2, verbose=0)[0]

    # Lista de hosts
    hosts = []

    # --- AQUI ESTÁ A CORREÇÃO: ADICIONA O PRÓPRIO PC ---
    meu_pc = pegar_meu_mac_ip()
    if meu_pc:
        hosts.append(meu_pc)
        print(f"✓ (Eu mesmo) {meu_pc['ip']} detectado.")

    # Adiciona os vizinhos encontrados na rede
    for sent, received in resultado:
        hosts.append({'ip': received.psrc, 'mac': received.hwsrc, 'vendor': None})

    print(f"✓ Total de {len(hosts)} dispositivos. Detalhando...\n")

    # 2. Análise Profunda
    for host in hosts:
        analisar_host(host['ip'], host['mac'], host['vendor'])

# --- MAIN ---

🔍 ARP Discovery

O scapy.ARP e scapy.Ether criam um pacote broadcast para varrer a sub-rede. A função scapy.srp() envia os pacotes e recebe respostas para mapear os vizinhos ativos (IP e MAC) instantaneamente.

💻 Identificação OS (TTL)

Ao enviar pacotes ICMP (Ping), o script intercepta a resposta e analisa o valor TTL (Time to Live). Valores nativos de ≤64 geralmente indicam Linux/Mac, enquanto ≤128 sugerem arquitetura Windows.

📡 Host Detection

A função pegar_meu_mac_ip() utiliza um "truque" de conexão UDP (abrindo socket para 8.8.8.8) para extrair o IP local de forma segura, junto à interface nativa do Scapy para pegar o próprio MAC.

Redes sem fio operam transmitindo pacotes por ondas de rádio (geralmente 2.4GHz ou 5GHz). A interceptação é trivial, exigindo criptografia robusta.

  • WPA2 (Wi-Fi Protected Access 2): O padrão da década, utilizando AES e CCMP. É vulnerável a ataques de dicionário e de força bruta caso a senha seja fraca (ataque ao 4-way handshake).
  • WPA3: O novo padrão. Traz o protocolo SAE (Simultaneous Authentication of Equals), protegendo contra ataques de força bruta offline e criptografando o tráfego aberto.
  • Mitigação & Segurança:
    - Desative o WPS (Vulnerável a ataques Pixie Dust / Reaver).
    - Oculte o SSID em redes críticas.
    - Isole redes IoT usando VLANs ou sub-redes convidadas.

O Bluetooth é um protocolo de rede Piconet de curto alcance operando em 2.4GHz com "frequency-hopping" (FHSS) para evitar interferências.

⚡ Bluetooth LE (BLE)

Oculto no Bluetooth 4.0+, o BLE não mantém conexão contínua. Envia pacotes curtos e dorme, sendo vital para IoT, smartwatches e Beacons.

🚀 Bluetooth 5.0+

Aumenta a velocidade (2 Mbps), alcança até 240 metros sem obstáculos e tem capacidade estendida de broadcasting. Revolucionou os fones TWS.

🛡️ Riscos de Segurança

Ataques como BlueBorne ou Bluejacking podem comprometer dispositivos pareados. É vital desligar a visibilidade de dispositivos ("Discoverable") quando não estiver ativamente pareando algo.

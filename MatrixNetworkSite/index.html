> Análise de Código: ARP Scanner com Scapy

O script Python abaixo utiliza a biblioteca scapy para realizar o descobrimento de hosts em uma rede local através do protocolo ARP, além de tentar inferir o Sistema Operacional através de pacotes ICMP (Ping).

def identificar_os(ttl):
    if ttl <= 64:
        return "Linux/Android/Mac"
    elif ttl <= 128:
        return "Windows"
    else:
        return "Desconhecido"

# --- NOVIDADE: PEGAR DADOS DA PRÓPRIA MÁQUINA ---
def pegar_meu_mac_ip():
    try:
        # Pega a interface padrão que o Scapy está usando
        mac = scapy.get_if_hwaddr(scapy.conf.iface)

        # Pega o IP local (truque do socket UDP)
        s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        s.connect(('8.8.8.8', 1))
        ip = s.getsockname()[0]
        s.close()

        return {'ip': ip, 'mac': mac, 'vendor': 'ESTE DISPOSITIVO (HOST)'}
    except:
        return None

def analisar_host(ip, mac, vendor_pre_definido=None):
    print(f"\n[+] Analisando: {ip} ({mac})")

    if vendor_pre_definido:
        vendor = vendor_pre_definido
        os_guess = "Windows/Linux (Host Local)"
    else:
        vendor = get_mac_vendor(mac)
        os_guess = "Não respondeu Ping"
        try:
            resp = scapy.sr1(IP(dst=ip) / ICMP(), timeout=1, verbose=0)
            if resp:
                os_guess = f"{identificar_os(resp.ttl)} (TTL={resp.ttl})"
        except:
            pass

    print(f"    ► Fabricante: {vendor}")
    print(f"    ► Sistema: {os_guess}")
    print("-" * 50)

def escanear_rede_ultimate(ip_range):
    print(f"\n🚀 SCAPY SCANNER - Iniciando em {ip_range}")
    print("=" * 60)

    # 1. ARP Discovery (Vê os Vizinhos)
    arp = scapy.ARP(pdst=ip_range)
    ether = scapy.Ether(dst="ff:ff:ff:ff:ff:ff")
    pacote = ether / arp
    resultado = scapy.srp(pacote, timeout=2, verbose=0)[0]

    hosts = []

    # --- AQUI ESTÁ A CORREÇÃO: ADICIONA O PRÓPRIO PC ---
    meu_pc = pegar_meu_mac_ip()
    if meu_pc:
        hosts.append(meu_pc)
        print(f"✓ (Eu mesmo) {meu_pc['ip']} detectado.")

    # Adiciona os vizinhos encontrados
    for sent, received in resultado:
        hosts.append({'ip': received.psrc, 'mac': received.hwsrc, 'vendor': None})

    print(f"✓ Total de {len(hosts)} dispositivos. Detalhando...\n")

    for host in hosts:
        analisar_host(host['ip'], host['mac'], host['vendor'])

if __name__ == "__main__":

        s.close()

        base_ip = ".".join(meu_ip.split('.')[:3]) + ".1/24"
        escanear_rede_ultimate(base_ip)
    except Exception as e:

Explicação das Etapas Chave

  • ARP Spoofing/Discovery: A função scapy.ARP() é configurada com um IP de destino (ou faixa de IPs) e envelopada em um quadro Ethernet em modo Broadcast (ff:ff:ff:ff:ff:ff). Quando enviado (scapy.srp), todos os dispositivos da sub-rede que possuem aquele IP respondem com seus endereços MAC, confirmando sua existência na rede local.
  • Inferência de Sistema Operacional (TTL): A função identificar_os() analisa o valor de Time-To-Live (TTL) de respostas ICMP. Geralmente, sistemas Linux inicializam seus pacotes com TTL de 64, enquanto sistemas Windows utilizam 128. Essa é uma heurística passiva e útil para adivinhar a família do SO.
  • Coleta do Host Local: O truque do socket.SOCK_DGRAM enviando dados para o Google DNS (8.8.8.8) obriga o sistema operacional do host a escolher a interface de rede ativa que tem rota para a internet. O IP atribuído a essa interface é então capturado por getsockname()[0], evitando capturar interfaces de loopback ou virtuais adormecidas.

> Redes Wi-Fi e Bluetooth: Fundamentos e Segurança

O espectro sem fio (RF) transformou a maneira como nos conectamos, substituindo cabos por ondas eletromagnéticas invisíveis. Abaixo, exploramos os dois protocolos dominantes de curto/médio alcance.

1. IEEE 802.11 (Wi-Fi)

O Wi-Fi utiliza transmissões de rádio nas bandas de 2.4 GHz, 5 GHz e, mais recentemente, 6 GHz. Operar através do "ar" significa que a infraestrutura não tem barreiras físicas; qualquer antena na vizinhança pode interceptar os pacotes de dados. A segurança depende inteiramente da criptografia aplicada aos pacotes.

  • Vantagens: Altas taxas de transferência de dados (especialmente nos padrões AC e AX/Wi-Fi 6), longo alcance relativo (até 100m) e forte interoperabilidade.
  • Desvantagens: Vulnerável a interferências de outros eletrônicos, paredes espessas e ataques de negação de serviço (Deauthentication).
  • Segurança: Antigos padrões como WEP e WPA são considerados quebrados. O WPA2 (AES) continua sendo o padrão de fato da indústria, porém requer senhas fortes devido à vulnerabilidade no seu 4-Way Handshake. O mais recente, WPA3, utiliza SAE (Simultaneous Authentication of Equals) tornando ataques de dicionário offline virtualmente impossíveis.

2. Bluetooth & BLE (Bluetooth Low Energy)

Bluetooth é voltado para Personal Area Networks (PANs). Enquanto a versão clássica lida com streaming contínuo (áudio, fones), o Bluetooth Low Energy (BLE) foi projetado para pequenos bursts de dados, permitindo que dispositivos operem por meses com baterias minúsculas.

  • Vantagens: Consumo de energia extremamente eficiente, pareamento rápido, excelente para sensores IoT, smartwatches e teclados.
  • Desvantagens: Baixo alcance prático (cerca de 10 a 30 metros), taxa de transmissão muito baixa, não serve para roteamento pesado de internet.
  • Segurança: Sujeito a ataques de interceptação na fase de pareamento (MITM) e ataques de "Spoofing", caso os perfis GATT não exijam criptografia e autenticação estrita (Pin Code ou Just Works). Dispositivos BLE costumam alternar seus endereços MAC aleatoriamente para evitar rastreamento de localização.

> Escaneamento de Rede com Scapy

Abaixo detalhamos a estrutura do código Python fornecido, que realiza uma varredura passiva e ativa na rede local, combinando Scapy para pacotes personalizados e manipulação de Sockets.

import scapy.all as scapy
from scapy.layers.inet import IP, TCP, ICMP
import socket
import requests
import time

def get_mac_vendor(mac_address)

Propósito: Converter o MAC (camada física) no nome legível da fabricante (OUI).

Detalhes: Geralmente faz uma requisição para APIs públicas (como macvendors.com) usando os primeiros 6 caracteres hexadecimais do MAC para descobrir se é um dispositivo Apple, Samsung, Intel, etc.

def identificar_os(ttl)

Propósito: Realizar Fingerprinting passivo baseando-se no Time-To-Live (TTL).

Detalhes: Dispositivos na rede iniciam seus pacotes IP com valores de TTL padrão. Linux e Android usam 64. Windows usa 128. Roteadores Cisco costumam usar 255. O script intercepta o TTL do pacote de resposta e supõe o SO hospedeiro com alta precisão.

def pegar_meu_mac_ip()

Propósito: Coletar credenciais do host atual sem depender de comandos ipconfig / ifconfig.

Detalhes: Usa o scapy.get_if_hwaddr() para ler o próprio endereço MAC e estabelece uma rota UDP falsa (socket) direcionada ao Google DNS (8.8.8.8) apenas para forçar o Sistema Operacional a revelar qual IP de interface local foi usado para essa rota.

def analisar_host(ip, mac, vendor_pre_definido=None)

Propósito: Construir um dossiê sobre o nó específico da rede.

Detalhes: Emite um pacote ICMP (Ping) construído do zero via Scapy: scapy.sr1(IP(dst=ip)/ICMP()). Aguarda 1 segundo e passa o TTL da resposta para identificar_os(). Exibe de forma centralizada os resultados no terminal.

def escanear_rede_ultimate(ip_range)

Propósito: A função motriz de toda a varredura.

Detalhes: Gera um ARP Request em Broadcast (MAC ff:ff:ff:ff:ff:ff) gritando "Quem tem esse IP?". Todos os aparelhos vivos respondem com seus endereços MAC reais. Ele varre o range (como 192.168.1.1/24), injeta o próprio dispositivo no índice inicial da lista, e logo depois delega cada resposta interceptada para o analisar_host().

> Redes Sem Fio (IEEE 802.11)

O Wi-Fi é a principal via de acesso às LANs modernas. Sua arquitetura traz facilidades, mas expande drasticamente a superfície de ataque.

Segurança e Criptografia

  • WEP / WPA / TKIP: Totalmente obsoletos e facilmente quebráveis via ataques estatísticos (Aircrack-ng).
  • WPA2 (AES-CCMP): Padrão de mercado atual. Seguro contra quebras matemáticas, mas ainda vulnerável a ataques de dicionário e força-bruta sobre o 4-Way Handshake (PMKID).
  • WPA3 (SAE): Substitui a PSK por Simultaneous Authentication of Equals. Resiste à força-bruta offline, mesmo se a senha for fraca.

Bandas e Frequências

  • 2.4 GHz: Maior alcance e poder de penetração em paredes. Pior velocidade e maior interferência (apenas 3 canais não-sobrepostos: 1, 6 e 11).
  • 5 GHz / 6 GHz: Velocidades massivas (802.11ac / 802.11ax), menor alcance. Virtualmente livre de interferência vizinha.

> Análise de Bluetooth (IEEE 802.15.1)

Embora criado para curtas distâncias (PANs), antenas direcionais podem captar e explorar sinais Bluetooth a quilômetros de distância.

Padrões e Evolução

  • Bluetooth Classic (BR/EDR): Usado para streaming contínuo (fones de ouvido sem fio, caixas de som, transferência de arquivos antigos). Alto consumo de energia.
  • Bluetooth Low Energy (BLE / Smart): Introduzido no BT 4.0. Usado por IoT, smartwatches, tags de localização. Envia dados intermitentes para economizar 99% da bateria.

Vetores de Ataque Comuns

  • Bluejacking: Envio de spam e mensagens irritantes em massa abusando do protocolo de descoberta.
  • Bluesnarfing: Falha crítica em pareamentos antigos que permite acessar a agenda telefônica e mensagens sem o PIN.
  • BlueBorne: Vulnerabilidade de RCE (Remote Code Execution) gravíssima que afeta as pilhas Bluetooth no Kernel do Windows, Android e Linux, dispensando pareamento.
